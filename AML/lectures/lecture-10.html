Short Notes & Visual Summary

Quick summary and key concepts for Lecture 10 (PCA):

Key PCA Principles
  • Goal: Reduce the number of features (\(p \to k\)) while preserving maximum variance/signal and removing noise/redundancy.
  • Selection vs. Extraction: Feature Selection keeps a subset of existing feature axes. Feature Extraction (PCA) rotates coordinates to construct new orthogonal axes \(PC_1, PC_2, \dots\) that align with true maximum variance.
  • Mean Centering: Mandatory first step (\(X_c = X - \mathbf{1}\mu^\top\)) so that variance is measured relative to the data centroid.
  • Eigendecomposition: The principal directions \(v_j\) are the unit eigenvectors of the sample covariance matrix \(S\), and the variance captured along \(v_j\) equals the corresponding eigenvalue \(\lambda_j\).
  • Explained Variance Ratio (EVR): \(\text{EVR}_j = \frac{\lambda_j}{\sum_{\ell=1}^p \lambda_\ell}\). Select \(k\) components based on scree plot elbow or cumulative variance threshold (\(\ge 90\%\)).

Why Dimensionality Reduction?

1.1 The Curse of High Dimensionality

When a dataset contains many features (\(p\)), each observation represents a point in \(p\)-dimensional space. While more features provide richer inputs, performance does not grow indefinitely. Beyond a certain point, uninformative or redundant features add random noise, inflate variance, and trigger an \(O(p^2)\) computational cost explosion.

Image Representation Example

Consider identifying an object inside an image of size \(m \times m\) pixels (\(p = m^2\)):

  • Full Image (\(m \times m\)): Contains the target object along with vast uninformative background pixels.
  • Cropped Object (\(f \times f\)): Contains 100% of the useful signal for shape recognition.

Model accuracy plateaus at \(f^2\) pixels, whereas processing the full \(m^2\) image multiplies computation without adding predictive value.

1.2 Feature Selection vs. Feature Extraction

Method Mechanism Pros & Cons
Feature Selection Keeps a subset of original feature axes \(\{x_1, x_2\}\) and discards axis \(x_3\) completely. Preserves original feature interpretability, but loses information if signal is spread diagonally across features.
Feature Extraction (PCA) Constructs new rotated orthogonal axes: \(PC_1 = w_1 x_1 + w_2 x_2 + \dots + w_p x_p\). Captures maximum variance along diagonal spreads; however, components become linear combinations of all features.

1.3 Principal Component Analysis (PCA) Defined

Definition of PCA

Principal Component Analysis (PCA) is an unsupervised linear feature-extraction technique that finds a new set of orthogonal coordinate axes (principal components) along which the variance of the data is maximized.

Building Blocks & Data Preprocessing

2.1 Notation & Data Matrix Setup

  • \(n\): Number of training observations (rows).
  • \(p\): Number of original features (columns).
  • \(k\): Number of retained principal components (\(k \le p\)).
  • \(X \in \mathbb{R}^{n \times p}\): Original uncentered data matrix.
  • \(\mu \in \mathbb{R}^{p \times 1}\): Column mean vector where \(\mu_j = \frac{1}{n}\sum_{i=1}^n x_{ij}\).
  • \(X_c \in \mathbb{R}^{n \times p}\): Mean-centered data matrix.
  • \(S \in \mathbb{R}^{p \times p}\): Sample covariance matrix.

2.2 Step 1: Mean Centering (\(X_c = X - \mathbf{1}\mu^\top\))

Before applying PCA, we must subtract feature means from every observation:

$$X_c = X - \mathbf{1}\mu^\top$$

Where \(\mathbf{1} \in \mathbb{R}^{n \times 1}\) is a column vector of ones, making \(\mathbf{1}\mu^\top\) an \(n \times p\) matrix replicating the mean row across all observations.

Why Mean Centering is Compulsory

PCA measures variance relative to the coordinate origin \((0, 0, \dots, 0)\). If data is not mean-centered, the offset from the origin distorts the variance calculation, forcing the first principal component to point toward the mean rather than the direction of true spread.

Numerical Running Example (3 Houses, 2 Features)

Consider 3 houses (\(n=3\)) measured by Bedroom area (\(f_1\)) and Washroom area (\(f_2\)):

$$X = \begin{bmatrix} 2 & 1 \\ 4 & 3 \\ 6 & 5 \end{bmatrix}, \quad \mu = \begin{bmatrix} 4 \\ 3 \end{bmatrix} \implies \mathbf{1}\mu^\top = \begin{bmatrix} 4 & 3 \\ 4 & 3 \\ 4 & 3 \end{bmatrix}$$ $$X_c = X - \mathbf{1}\mu^\top = \begin{bmatrix} 2-4 & 1-3 \\ 4-4 & 3-3 \\ 6-4 & 5-3 \end{bmatrix} = \begin{bmatrix} -2 & -2 \\ 0 & 0 \\ 2 & 2 \end{bmatrix}$$

2.3 Standardization: When Scale Matters

If features are measured in different units (e.g., House Price in Rupees vs. Age in Years), divide each centered feature by its sample standard deviation \(s_j\):

$$z_{ij} = \frac{x_{ij} - \mu_j}{s_j}, \quad s_j = \sqrt{\frac{1}{n-1}\sum_{i=1}^n (x_{ij} - \mu_j)^2}$$
  • Use Centering Only: When features share comparable units and original variance magnitudes carry meaningful domain signal.
  • Use Standardization: When features have different units or wildly different variance scales, preventing large-scale variables from dominating PCA artificially.

Formulation: Maximizing Variance

3.1 1D Projection onto Unit Direction \(u\)

Let \(u \in \mathbb{R}^{p \times 1}\) be a unit direction vector (\(\|u\| = 1\)). The scalar projection length of a centered observation \(x_i\) onto \(u\) is given by the dot product:

$$z_i = u^\top x_i$$

3.2 Variance vs. Reconstruction Error Duality

By Pythagorean decomposition, the squared norm of observation \(x_i\) decomposes into projected length \(z_i^2\) and orthogonal reconstruction error \(\|e_i\|^2\):

$$\|x_i\|^2 = z_i^2 + \|e_i\|^2$$

Since the total norm \(\sum \|x_i\|^2\) is fixed by the dataset, maximizing projected variance is mathematically equivalent to minimizing total reconstruction error:

$$\max_{\|u\|=1} \text{Var}(z) \iff \min_{\|u\|=1} \sum_{i=1}^n \|e_i\|^2$$

3.3 Derivation of Variance Formula (\(u^\top S u\))

The sample variance of the projected scalar coordinates \(z_i = u^\top x_i\) (since mean \(\bar{z} = 0\)) is:

$$\text{Var}(z) = \frac{1}{n-1} \sum_{i=1}^n (u^\top x_i)^2 = \frac{1}{n-1} \sum_{i=1}^n (u^\top x_i)(x_i^\top u) = u^\top \left( \frac{1}{n-1} \sum_{i=1}^n x_i x_i^\top \right) u$$ $$\text{Var}(z) = u^\top S u$$

Where \(S = \frac{1}{n-1} X_c^\top X_c\) is the \(p \times p\) sample covariance matrix.

4

Covariance & Eigendecomposition

4.1 Sample Covariance Matrix \(S = \frac{1}{n-1} X_c^\top X_c\)

Sample covariance measures how two centered features \(f_j\) and \(f_k\) co-vary linearly:

$$\text{Cov}(f_j, f_k) = \frac{1}{n-1} \sum_{i=1}^n (x_{ij} - \mu_j)(x_{ik} - \mu_k)$$

The matrix product \(S = \frac{1}{n-1} X_c^\top X_c\) constructs all pairwise feature covariances simultaneously:

Continuing Running Example

$$S = \frac{1}{3-1} \begin{bmatrix} -2 & 0 & 2 \\ -2 & 0 & 2 \end{bmatrix} \begin{bmatrix} -2 & -2 \\ 0 & 0 \\ 2 & 2 \end{bmatrix} = \frac{1}{2} \begin{bmatrix} 8 & 8 \\ 8 & 8 \end{bmatrix} = \begin{bmatrix} 4 & 4 \\ 4 & 4 \end{bmatrix}$$

4.2 Eigenvalues (\(\lambda_j\)) and Eigenvectors (\(v_j\))

Maximizing \(u^\top S u\) subject to \(\|u\|=1\) using Lagrange multipliers yields the characteristic matrix equation:

$$S v = \lambda v \iff |S - \lambda I| = 0$$
  • Eigenvectors (\(v_j\)): Unit direction vectors specifying the principal component axes.
  • Eigenvalues (\(\lambda_j\)): Scalar values representing the exact variance captured along \(v_j\).

Eigenvalues & Eigenvectors for Running Example

$$|S - \lambda I| = \begin{vmatrix} 4-\lambda & 4 \\ 4 & 4-\lambda \end{vmatrix} = (4-\lambda)^2 - 16 = 0 \implies \lambda^2 - 8\lambda = 0$$ $$\lambda_1 = 8, \quad \lambda_2 = 0$$ $$\text{For } \lambda_1 = 8: \quad v_1 = \frac{1}{\sqrt{2}} \begin{bmatrix} 1 \\ 1 \end{bmatrix} \quad (\text{Overall House Size})$$ $$\text{For } \lambda_2 = 0: \quad v_2 = \frac{1}{\sqrt{2}} \begin{bmatrix} 1 \\ -1 \end{bmatrix} \quad (\text{Allocation Difference})$$

4.3 Component Ordering & Score Calculation

Sort eigenpairs by descending eigenvalues (\(\lambda_1 \ge \lambda_2 \ge \dots \ge \lambda_p\)). Select the top \(k\) eigenvectors to form projection matrix \(W_k = [v_1, v_2, \dots, v_k] \in \mathbb{R}^{p \times k}\). The transformed lower-dimensional scores \(Z \in \mathbb{R}^{n \times k}\) are:

$$Z = X_c W_k$$

PCA Pipeline & Scree Plots

5.1 Step-by-Step ML Pipeline & Data Leakage

  1. Split Data: Perform train-test split FIRST before any preprocessing.
  2. Fit Parameters on Train Only: Compute training feature means \(\mu_{tr}\), standard deviations \(s_{tr}\), and projection matrix \(W_k\) on training data exclusively.
  3. Transform Train & Test: Apply stored training statistics: $$Z_{train} = X_{c, train} W_k, \quad Z_{test} = (X_{test} - \mathbf{1}_{test}\mu_{tr}^\top) W_k$$
Never Leak Test Data into PCA

Never re-fit PCA or re-compute feature means on test/validation data. Fitting PCA on the full dataset before splitting leaks test distribution information into training, producing unrealistically optimistic evaluation scores.

5.2 Explained Variance Ratio & Scree Plots

Total variance equals the trace of the covariance matrix \(\text{trace}(S) = \sum_{j=1}^p \lambda_j\). The Explained Variance Ratio (EVR) of component \(j\) is:

$$\text{EVR}_j = \frac{\lambda_j}{\sum_{\ell=1}^p \lambda_\ell}, \quad \text{Cumulative EVR}_k = \frac{\sum_{j=1}^k \lambda_j}{\sum_{\ell=1}^p \lambda_\ell}$$
  • Scree Plot (Elbow Rule): A bar/line plot of eigenvalues ordered by index. Choose \(k\) at the "elbow" point where additional components yield diminishing returns.
  • Cumulative Variance Cutoff: Retain the minimum \(k\) reaching 90% or 95% total variance.

5.3 When PCA Fails & Limitations

Limitations of PCA
  • Non-Linear Manifolds: PCA is a linear transformation. It fails on non-linear data distributions (e.g., concentric circles, Swiss roll). Use kernel PCA or t-SNE / UMAP for non-linear structures.
  • Sensitivity to Outliers: Outliers dramatically inflate sample variance, pulling principal components toward outlier spikes.
  • Interpretability Loss: Principal components \(PC_j\) are linear combinations of all original variables, losing direct feature semantics.
