Short Notes & Visual Summary

Quick summary and core takeaways for Lecture 11 (Regularization):

Key Regularization Takeaways
  • Symptom of Overfitting: Abnormally large coefficient magnitudes (\(w_j \to \infty\)), causing hypersensitivity to small input variations (High Variance).
  • Regularization Goal: Add a penalty term \(P(w)\) to the loss function to penalize large weights, trading a tiny increase in training bias for a dramatic reduction in variance.
  • Ridge Regression (L2): Penalty \(= \lambda \sum w_j^2\). Shrinks coefficients toward zero, handles multicollinearity by guaranteeing matrix invertibility \((X^\top X + \lambda I)^{-1}\), but never sets coefficients to exact zero.
  • Lasso Regression (L1): Penalty \(= \lambda \sum |w_j|\). Sharp diamond constraint region forces uninformative feature weights to exact zero (\(w_j = 0\)), providing automatic feature selection and sparse models.
  • Mandatory Preprocessing: Features MUST be standardized before regularizing so that feature scales do not distort penalty strength.

Overfitting & Coefficient Explosion

1.1 Why Do We Need Regularization?

When training machine learning models, an unconstrained model often fits every noisy data point in the training set. While training loss drops to zero, the model memorizes random noise rather than learning true underlying patterns, leading to poor test generalization (Overfitting).

1.2 Coefficient Magnitude as Overfitting Symptom

The Coefficient Explosion Symptom

Overfitted models exhibit abnormally large coefficient values (\(m \to \infty\)). A steep slope means a tiny change in input \(\Delta x\) produces a massive jump in prediction \(\Delta \hat{y}\), creating extreme hypersensitivity and high variance.

Comparison Example: Gentle vs. Overfit Model

  • Model A (Gentle, Robust): \(\hat{y} = 2x + 10 \implies\) Change of \(\Delta x = 0.5\) yields \(\Delta \hat{y} = 1.0\).
  • Model B (Overfit, High Variance): \(\hat{y} = 30x - 18 \implies\) Change of \(\Delta x = 0.5\) yields \(\Delta \hat{y} = 15.0\).

Model B contorts to hit training outliers, creating high variance on unseen data.

1.3 Definition of Regularized Loss

Regularization modifies the cost function by appending a penalty term dependent on model weights:

$$\mathcal{L}_{\text{regularized}}(w) = \mathcal{L}_{\text{data}}(w) + \lambda P(w)$$

Where \(\lambda \ge 0\) is the regularization hyperparameter controlling penalty intensity.

L2 Regularization: Ridge Regression

2.1 Ridge Loss Function (\(\mathcal{L} + \lambda m^2\))

In simple linear regression (\(y = mx + c\)), Ridge Regression (L2) adds a penalty proportional to the squared slope:

$$\mathcal{L}_{\text{Ridge}}(m, c) = \sum_{i=1}^n (y_i - m x_i - c)^2 + \lambda m^2$$

2.2 2D Closed-Form Slope Derivation

Step-by-Step Derivation

  1. Partial derivative w.r.t. intercept \(c\): $$\frac{\partial \mathcal{L}_{\text{Ridge}}}{\partial c} = -2 \sum_{i=1}^n (y_i - m x_i - c) = 0 \implies c = \bar{y} - m\bar{x}$$
  2. Substitute \(c = \bar{y} - m\bar{x}\) back into Loss: $$\mathcal{L}_{\text{Ridge}}(m) = \sum_{i=1}^n \left[(y_i - \bar{y}) - m(x_i - \bar{x})\right]^2 + \lambda m^2$$
  3. Differentiate w.r.t. slope \(m\) and set to 0: $$\frac{d \mathcal{L}_{\text{Ridge}}}{dm} = -2 \sum_{i=1}^n (x_i - \bar{x})\left[(y_i - \bar{y}) - m(x_i - \bar{x})\right] + 2\lambda m = 0$$ $$-\sum_{i=1}^n (x_i - \bar{x})(y_i - \bar{y}) + m \sum_{i=1}^n (x_i - \bar{x})^2 + \lambda m = 0$$
  4. Solve for \(m_{\text{Ridge}}\): $$m_{\text{Ridge}} = \frac{\sum_{i=1}^n (x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^n (x_i - \bar{x})^2 + \lambda}$$

2.3 Bias-Variance Tradeoff Adjustment

Notice that hyperparameter \(\lambda\) sits directly in the denominator of \(m_{\text{Ridge}}\):

  • \(\lambda = 0\): Standard OLS slope. High variance if data is noisy.
  • \(\lambda > 0\): Denominator increases, shrinking slope \(m\) toward zero. The model accepts a small increase in Bias (slightly higher training error) to achieve a massive reduction in Variance on test data.
  • \(\lambda \to \infty\): \(m_{\text{Ridge}} \to 0\), producing a flat horizontal line \(\hat{y} = \bar{y}\) (Underfitting).

Multi-Feature Ridge & Key Properties

3.1 Matrix Normal Equation \(\beta_{\text{Ridge}} = (X^\top X + \lambda I)^{-1} X^\top y\)

For multiple linear regression with \(p\) features, the total Ridge loss in matrix form is:

$$\mathcal{L}_{\text{Ridge}}(\beta) = (y - X\beta)^\top (y - X\beta) + \lambda \beta^\top \beta$$

Setting the gradient \(\nabla_\beta \mathcal{L} = 0\) yields the Ridge Normal Equation:

$$\beta_{\text{Ridge}} = (X^\top X + \lambda I)^{-1} X^\top y$$

3.2 Multicollinearity & Guaranteed Invertibility

Why Ridge Handles Multicollinearity

In standard OLS, when features are highly correlated (multicollinear), \(X^\top X\) is singular or near-singular, making \((X^\top X)^{-1}\) fail or explode. Adding \(\lambda I\) adds positive numbers \(\lambda > 0\) to the main diagonal of \(X^\top X\), guaranteeing that \((X^\top X + \lambda I)\) is strictly positive definite and always invertible.

3.3 Asymmetric Shrinkage & Non-Zero Limits

  • Coefficients Never Reach Exact Zero: In Ridge (L2), weights shrink asymptotically as \(\lambda \to \infty\), becoming tiny (e.g., \(10^{-5}\)), but never reach exact zero. All original features remain in the model.
  • Asymmetric Shrinkage: Because penalty is \(\lambda w_j^2\), larger coefficients pay quadratically higher penalties (\(w_1 = 5000 \implies 2.5\times 10^7 \lambda\)). Thus, larger weights are penalized much more aggressively than small weights.

L1 Regularization: Lasso Regression

4.1 Lasso Loss Function (\(\mathcal{L} + \lambda \sum |w_j|\))

Lasso (Least Absolute Shrinkage and Selection Operator) applies an L1 penalty proportional to the sum of absolute coefficient values:

$$\mathcal{L}_{\text{Lasso}}(w) = \sum_{i=1}^n (y_i - \hat{y}_i)^2 + \lambda \sum_{j=1}^p |w_j|$$

4.2 Automatic Feature Selection (Sparsity)

Lasso as Automatic Feature Selection

Unlike Ridge, Lasso drives uninformative or redundant feature weights to exact zero (\(w_j = 0\)). This produces a sparse model containing only a subset of non-zero features, performing automatic feature selection.

4.3 L1 vs. L2 Geometric Constraint Boundaries

Consider regularized regression as minimizing OLS error subject to a hard constraint region:

  • L2 (Ridge) Constraint: \(w_1^2 + w_2^2 \le r^2\) forms a smooth circle/sphere. The expanding elliptical OLS loss contours touch the smooth circle boundary at non-zero points \((w_1, w_2)\).
  • L1 (Lasso) Constraint: \(|w_1| + |w_2| \le r\) forms a diamond/rhombus with sharp corners directly on the coordinate axes (\((r, 0)\) or \((0, r)\)). Elliptical loss contours frequently intersect these sharp corners first, driving \(w_1 = 0\) or \(w_2 = 0\).

Comparison Matrix & Practical Workflow

5.1 OLS vs. Ridge vs. Lasso Comparison Matrix

Feature OLS Regression Ridge (L2) Lasso (L1)
Penalty Term None (\(\lambda = 0\)) \(\lambda \sum w_j^2\) (L2 norm) \(\lambda \sum |w_j|\) (L1 norm)
Coefficients = 0? No No (Shrinks near 0, never exact 0) Yes (Drives uninformative \(w_j \to 0\))
Feature Selection No No (Retains all \(p\) features) Yes (Automatic Sparse Selection)
Closed-Form Solution \((X^\top X)^{-1} X^\top y\) \((X^\top X + \lambda I)^{-1} X^\top y\) No closed-form (Coordinate Descent)
Multicollinearity Fails (Singular matrix) Excellent (Always invertible) Selects one feature arbitrarily

5.2 Feature Scaling Requirement Before Regularization

Standardization is Mandatory

Because regularization penalizes absolute coefficient values \(w_j\), features with smaller raw scales (e.g. Income in Millions) naturally require larger weights \(w_j\) and will be penalized unfairly. Always standardize features (\(z\)-score scaling) prior to running Ridge or Lasso.

5.3 Hyperparameter Tuning via Cross-Validation

Hyperparameter \(\lambda\) controls model complexity. Use \(K\)-Fold Cross-Validation on the training set to select the optimal \(\lambda^*\) that minimizes validation MSE:

  • Too Small \(\lambda\): High variance, overfitting.
  • Optimal \(\lambda^*\): Lowest cross-validation error (optimal Bias-Variance tradeoff).
  • Too Large \(\lambda\): High bias, underfitting.
