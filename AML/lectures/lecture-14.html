Short Notes & Visual Summary

Core principles and summary cheat-sheet for Lecture 14:

Key MLE & Logistic Regression Takeaways
  • Probability vs. Likelihood: In probability \(P(\text{Data} \mid \theta)\), the model parameter \(\theta\) is fixed and we ask how likely various outcomes are. In likelihood \(L(\theta; \text{Data})\), the observed data is fixed and we ask which candidate parameter \(\theta\) best explains that data.
  • MLE Principle: Maximum Likelihood Estimation selects parameters \(\hat{\theta} = \arg\max_\theta L(\theta; D)\) that make the observed dataset most plausible under the model.
  • Why Accuracy Alone Fails: Discrete misclassification count cannot break ties between multiple lines that achieve 100% training accuracy. We require a smooth, continuous confidence score.
  • Linear Score & Sigmoid: Linear score \(z = \mathbf{x}^\top \beta\). Decision boundary is \(z = 0\). The Sigmoid function \(\sigma(z) = \frac{1}{1 + e^{-z}}\) maps \((-\infty, \infty) \to (0, 1)\), establishing estimated class probability \(\hat{p}_i = P(Y_i = 1 \mid x_i) = \sigma(z_i)\).
  • Bernoulli Likelihood: Using the compact selector formula \(P(y_i \mid x_i; \beta) = \hat{p}_i^{y_i} (1 - \hat{p}_i)^{1 - y_i}\), the dataset joint likelihood is \(L(\beta) = \prod_{i=1}^n \hat{p}_i^{y_i} (1 - \hat{p}_i)^{1 - y_i}\).
  • Binary Cross-Entropy (BCE): Taking the negative average log-likelihood yields the BCE loss function: $$\text{BCE}(\beta) = -\frac{1}{n} \sum_{i=1}^n \left[ y_i \log(\hat{p}_i) + (1 - y_i) \log(1 - \hat{p}_i) \right]$$
  • Asymptotic Punishment: When an actual positive example (\(y = 1\)) is predicted with near-zero probability (\(\hat{p} \to 0\)), loss \(-\log(\hat{p}) \to +\infty\). BCE severely penalizes confidently wrong predictions.
  • Convexity & Solvers: BCE is strictly convex with no local minima traps. However, because the sigmoid nonlinearly couples parameters to predictions, there is no closed-form normal equation—iterative gradient descent is required.
01

From Probability to Maximum Likelihood Estimation (MLE)

1.1 The Probability vs. Likelihood Duality

While probability and likelihood share the exact same algebraic formula, their fundamental roles in statistics are completely reversed:

Question Probability Likelihood
What is fixed? Model parameter \(\theta\) (known) Observed Data \(D\) (recorded facts)
What varies? Future possible outcomes \(X\) Candidate parameters \(\theta\)
Notation \(P(\text{Data} \mid \text{Parameter})\) \(L(\text{Parameter}; \text{Data})\)
Core Question "Assuming this model is true, how likely is this outcome?" "Given this observed outcome, which parameter best explains it?"

1.2 Coin Toss Likelihood Derivation

Suppose a coin is tossed 10 times and we observe exactly 7 Heads (\(X = 7\)). For any candidate probability of heads \(p \in [0, 1]\), the likelihood function is:

$$L(p; X = 7) = \binom{10}{7} p^7 (1 - p)^3$$

Evaluating this function at different candidate values:

  • \(L(p = 0.5; X = 7) = \binom{10}{7} (0.5)^7 (0.5)^3 \approx 0.117\)
  • \(L(p = 0.8; X = 7) = \binom{10}{7} (0.8)^7 (0.2)^3 \approx 0.201\)
  • \(L(p = 0.7; X = 7) = \binom{10}{7} (0.7)^7 (0.3)^3 \approx 0.267\) (Peak of the likelihood curve)

1.3 The MLE Criterion (\(\hat{\theta} = \arg\max L\))

The Principle of Maximum Likelihood Estimation
$$\hat{\theta}_{\text{MLE}} = \arg\max_{\theta} L(\theta; D) = \arg\max_{\theta} P(D \mid \theta)$$

MLE chooses the parameter vector that makes the data we actually observed as probable as possible. It is a frequentist plausibility score, not a probability distribution over \(\theta\).

02

Linear Score & The Sigmoid Mapping

2.1 Why Accuracy Alone Cannot Break Ties

Consider classifying student placement (Placed = 1, Not Placed = 0) using features IQ (\(x_1\)) and CGPA (\(x_2\)). Multiple different separating lines can separate all training points with 100% classification accuracy (zero misclassifications).

A discrete 0-or-1 accuracy metric produces a flat, piecewise constant loss surface. It provides zero gradient guidance to distinguish between a boundary that barely skims past an observation versus a boundary with large, confident margins. We need a soft confidence score.

2.2 Linear Score \(z\) & Decision Boundary \(z=0\)

We define a linear combination of input features:

$$z = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \dots + \beta_d x_d = \mathbf{x}^\top \beta$$
  • The decision boundary is the hyperplane where \(z = 0\).
  • Points with \(z > 0\) lie on the positive side; points with \(z < 0\) lie on the negative side.
  • The magnitude \(|z|\) reflects the directional distance from the boundary, representing the model's confidence.

2.3 Step Function Failure & The Sigmoid Function

A hard step function \(\hat{y} = 1\) if \(z \ge 0\) else \(0\) is non-differentiable at \(z = 0\) and has zero derivative everywhere else (\(\frac{d\hat{y}}{dz} = 0\)), preventing gradient-based learning. Furthermore, it treats \(z = 0.01\) and \(z = 10\) identically, completely discarding confidence.

To produce smooth, differentiable probabilities, logistic regression applies the Sigmoid (Logistic) Function:

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$
Properties of the Sigmoid Function
  • Bounded Range: Since \(e^{-z} > 0\) for all real \(z\), \(0 < \sigma(z) < 1\).
  • Center Point: At \(z = 0\) (on the boundary), \(\sigma(0) = \frac{1}{1 + 1} = 0.5\).
  • Asymptotic Limits: As \(z \to +\infty\), \(\sigma(z) \to 1\). As \(z \to -\infty\), \(\sigma(z) \to 0\).
  • Strict Monotonicity: Preserves order: if \(z_A > z_B\), then \(\sigma(z_A) > \sigma(z_B)\).
03

Bernoulli Model & Dataset Likelihood

3.1 Class Probabilities \(\hat{p}_i\) and \(1-\hat{p}_i\)

For each observation \(i\), the sigmoid output is defined as the model's estimated probability that \(Y_i = 1\):

$$\hat{p}_i = P(Y_i = 1 \mid \mathbf{x}_i; \beta) = \sigma(z_i) = \frac{1}{1 + e^{-\mathbf{x}_i^\top \beta}}$$

Since binary outcomes are complementary, the probability of class 0 is simply the remaining probability mass:

$$P(Y_i = 0 \mid \mathbf{x}_i; \beta) = 1 - \hat{p}_i$$

3.2 Compact Bernoulli Label Probability Formula

We unify both cases into a single mathematical expression using binary label \(y_i \in \{0, 1\}\) as an exponent selector:

$$q_i = P(y_i \mid \mathbf{x}_i; \beta) = \hat{p}_i^{y_i} (1 - \hat{p}_i)^{1 - y_i}$$
  • If \(y_i = 1\): \(q_i = \hat{p}_i^1 (1 - \hat{p}_i)^0 = \hat{p}_i\).
  • If \(y_i = 0\): \(q_i = \hat{p}_i^0 (1 - \hat{p}_i)^1 = 1 - \hat{p}_i\).

3.3 Joint Dataset Likelihood Under Conditional Independence

Assuming the observations \((x_1, y_1), \dots, (x_n, y_n)\) are conditionally independent given parameters \(\beta\), the joint likelihood of observing the entire dataset is the product of individual probabilities:

$$L(\beta) = \prod_{i=1}^n P(y_i \mid \mathbf{x}_i; \beta) = \prod_{i=1}^n \hat{p}_i^{y_i} (1 - \hat{p}_i)^{1 - y_i}$$
Why Likelihood Outperforms Accuracy

Consider two models that both correctly classify 4 points with 100% accuracy. Model A assigns probabilities \([0.90, 0.80, 0.85, 0.75]\) to the true classes (product \(L = 0.459\)). Model B assigns \([0.60, 0.55, 0.65, 0.60]\) (product \(L = 0.129\)). Likelihood decisively selects Model A because it assigned higher confidence to the actual truth.

04

Derivation & Behavior of BCE Loss

4.1 Why Log-Likelihood (Preventing Underflow)

Multiplying \(n\) probabilities between 0 and 1 causes severe numerical underflow. For example, \(0.5^{2000} \approx 10^{-602}\), which underflows to exact zero in standard 64-bit IEEE floating-point arithmetic.

Because the natural logarithm \(\log(x)\) is a strictly monotonically increasing function, \(\arg\max_\beta L(\beta) \equiv \arg\max_\beta \log L(\beta)\). It converts unstable products into numerically stable additions:

$$\ell(\beta) = \log L(\beta) = \sum_{i=1}^n \log\left(\hat{p}_i^{y_i} (1 - \hat{p}_i)^{1 - y_i}\right) = \sum_{i=1}^n \left[ y_i \log(\hat{p}_i) + (1 - y_i) \log(1 - \hat{p}_i) \right]$$

4.2 Converting Maximum Log-Likelihood to BCE Loss

In machine learning, optimization frameworks are standardly formulated as loss minimization rather than reward maximization. Multiplying the log-likelihood by \(-1\) and dividing by sample size \(n\) yields the Binary Cross-Entropy (BCE) Loss:

Binary Cross-Entropy Loss Equation
$$\text{BCE}(\beta) = -\frac{1}{n} \ell(\beta) = -\frac{1}{n} \sum_{i=1}^n \left[ y_i \log(\hat{p}_i) + (1 - y_i) \log(1 - \hat{p}_i) \right]$$

For an individual observation \(i\):

$$\mathcal{L}_i = \begin{cases} -\log(\hat{p}_i) & \text{if } y_i = 1 \\ -\log(1 - \hat{p}_i) & \text{if } y_i = 0 \end{cases}$$

4.3 Asymptotic Penalty for Confident Errors

The logarithmic loss behaves as follows:

  • If \(y_i = 1\) and \(\hat{p}_i = 0.99\): Loss is \(-\log(0.99) \approx 0.01\) (minimal penalty for confident correct prediction).
  • If \(y_i = 1\) and \(\hat{p}_i = 0.50\): Loss is \(-\log(0.50) \approx 0.693\) (moderate penalty for uncertainty).
  • If \(y_i = 1\) and \(\hat{p}_i \to 0\): Loss is \(-\log(\hat{p}_i) \to +\infty\) (infinite penalty for confident error).
Numerical Clipping in Production Libraries

Because \(\log(0)\) evaluates to \(-\infty\), machine learning libraries (such as PyTorch and Scikit-learn) clip predicted probabilities to \([\epsilon, 1 - \epsilon]\) (where \(\epsilon \approx 10^{-15}\)) to prevent \(\text{NaN}\) division errors.

05

Optimization, Convexity & The Complete Pipeline

5.1 Convexity of BCE & Need for Iterative Solvers

For linear logistic regression, the Binary Cross-Entropy loss function is strictly convex with respect to the weight vector \(\beta\). This means the loss surface forms a global bowl shape with no sub-optimal local minima—any local minimum found is guaranteed to be the global minimum.

However, unlike Ordinary Least Squares (OLS) where the normal equation \(\beta = (X^\top X)^{-1} X^\top y\) yields an instant closed-form solution, the nonlinear sigmoid function prevents analytical isolation of \(\beta\). We must find the optimal weights using iterative optimization (Gradient Descent, Newton-Raphson, or L-BFGS).

5.2 Regularized Logistic Objective (\(J(\beta) = \text{BCE} + \lambda R\))

When training data is linearly separable, unregularized logistic regression weights will explode to infinity (\(\|\beta\| \to \infty\)) to push \(\sigma(z) \to 0\) or \(1\). To prevent this coefficient explosion, we add L1 or L2 regularization penalties:

$$J(\beta) = \text{BCE}(\beta) + \lambda \|\beta\|_2^2 \quad \text{or} \quad J(\beta) = \text{BCE}(\beta) + \lambda \|\beta\|_1$$

5.3 Complete 8-Step End-to-End Mathematical Story

The Complete Logistic Regression Derivation Chain
  1. Input Features: Given feature vector \(\mathbf{x}_i\) for observation \(i\).
  2. Linear Score: Compute linear score \(z_i = \mathbf{x}_i^\top \beta\).
  3. Sigmoid Mapping: Pass \(z_i\) into sigmoid \(\sigma(z_i) = \frac{1}{1 + e^{-z_i}}\).
  4. Class Probability: Define estimated probability \(\hat{p}_i = P(Y_i = 1 \mid \mathbf{x}_i)\).
  5. Bernoulli Term: Formulate compact observed label probability \(q_i = \hat{p}_i^{y_i} (1 - \hat{p}_i)^{1 - y_i}\).
  6. Joint Likelihood: Multiply across all \(n\) observations: \(L(\beta) = \prod_{i=1}^n q_i\).
  7. Log-Likelihood: Take natural logarithm to convert product to sum: \(\ell(\beta) = \sum_{i=1}^n \log q_i\).
  8. BCE Objective: Negate and average to obtain \(\text{BCE}(\beta) = -\frac{1}{n} \ell(\beta)\), ready for minimization via Gradient Descent.
