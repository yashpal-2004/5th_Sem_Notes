1

The Network Layer Role & IPv4 Datagram Structure

1.1 Host-to-Host Delivery Model

The Network Layer transports packets from sending host to receiving host across interconnected routers, executing two core functions: Forwarding (local router action) and Routing (network-wide path selection).

1.2 20-Byte Base IPv4 Header Structure

Standard IPv4 header is 20 bytes (without options). Key fields include Source IP (32 bits), Destination IP (32 bits), Version (4), Header Length (IHL), Total Length, Protocol (e.g., 6 for TCP, 17 for UDP), TTL, and Header Checksum.

2

IPv4 Addressing Fundamentals

2.1 32-Bit Binary Notation to Dotted Decimal

IPv4 addresses are 32-bit integers written in 4 octets separated by dots (e.g., 192.168.1.1).

$$\text{IPv4 Address Space} = 2^{32} = 4,294,967,296 \text{ addresses}$$
3

Historical Classful Addressing

3.1 Class A, B, C Network Boundaries

  • Class A (0.0.0.0 to 127.255.255.255): 8-bit netid, 24-bit hostid ($16M$ hosts/net).
  • Class B (128.0.0.0 to 191.255.255.255): 16-bit netid, 16-bit hostid ($65K$ hosts/net).
  • Class C (192.0.0.0 to 223.255.255.255): 24-bit netid, 8-bit hostid ($254$ hosts/net).
4

Classless Inter-Domain Routing (CIDR)

4.1 CIDR Notation (/x)

CIDR (RFC 1519) abandoned rigid classes. Address format a.b.c.d/x indicates that the first $x$ bits specify the network prefix.

4.2 Subnet Mask Representation

A subnet mask has $x$ leading 1s followed by $32-x$ trailing 0s (e.g., /24 = 255.255.255.0).

4.3 Longest Prefix Match Rule in Routers

When forwarding a packet, a router searches its routing table and selects the entry whose subnet prefix matches the destination IP address with the longest bit-length ($x$).
