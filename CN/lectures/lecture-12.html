Load Balancing Fundamentals & Cloud Architecture

1.1 High Availability & Horizontal Scaling

Load Balancers sit in front of server pools, distributing incoming application traffic evenly across multiple backend instances to ensure High Availability (HA) and seamless horizontal scaling.

1.2 Virtual IP (VIP) Abstraction

Clients send requests to a single public Virtual IP (VIP). The Load Balancer proxies or forwards requests to internal Private IPs (DIPs) of backend servers.

2

Layer 4 (L4) vs. Layer 7 (L7) Load Balancing

2.1 L4 Network/Transport Load Balancing

Operates at TCP/UDP layer without inspecting application payloads. High throughput, low latency (e.g., AWS Network Load Balancer, IPVS).

2.2 L7 Application Load Balancing

Terminates TCP/TLS connections and inspects HTTP headers, URLs, cookies, and payloads to route traffic intelligently (e.g., NGINX, HAProxy, AWS ALB).

3

Load Balancing Scheduling Algorithms

3.1 Round Robin & Weighted Round Robin

Round Robin cycles sequentially through backend servers. Weighted Round Robin assigns higher traffic proportions to more powerful servers.

3.2 Least Connections Strategy

Directs new requests to the backend server currently handling the fewest active connections; optimal for long-lived sessions.

4

Consistent Hashing & Distributed Cache Distribution

4.1 The Traditional Hash Problem

Standard modulo hashing $\text{hash}(key) \pmod N$ causes nearly 100% of keys to remap when adding or removing a node ($N \to N+1$), invalidating caches.

4.2 Hash Ring Topology

Consistent Hashing maps both servers and keys onto a circular $2^{32}-1$ hash ring space. Adding or removing a server remaps only $K / N$ keys on average.

5

Global Server Load Balancing (GSLB) & DNS Routing

5.1 Multi-Region High Availability

Global Server Load Balancing (GSLB) routes user traffic across geographically dispersed data centers worldwide.

5.2 Anycast BGP Routing Mechanics

In Anycast, multiple data centers announce the same IP address via BGP. Internet routers automatically direct user packets to the topologically closest data center.
