Subnetting Mathematics & Variable Length Subnet Masking (VLSM)

1.1 Host Bit Borrowing Formula

To divide a network block into $2^b$ smaller subnets, borrow $b$ host bits for the network prefix:

$$\text{Number of Subnets} = 2^b$$ $$\text{Usable Hosts per Subnet} = 2^{32 - (x + b)} - 2$$

(Subtracting 2 for Network ID and Broadcast Address).

Step-by-Step Subnet Design & Aggregation

2.1 Practical Subnetting Example

Dividing 192.168.1.0/24 into 4 subnets ($b=2$ borrowed bits, new mask /26 = 255.255.255.192):

  • Subnet 0: 192.168.1.0/26 (Hosts: .1 to .62, Broadcast: .63)
  • Subnet 1: 192.168.1.64/26 (Hosts: .65 to .126, Broadcast: .127)
  • Subnet 2: 192.168.1.128/26 (Hosts: .129 to .190, Broadcast: .191)
  • Subnet 3: 192.168.1.192/26 (Hosts: .193 to .254, Broadcast: .255)

Dynamic Host Configuration Protocol (DHCP)

3.1 Plug-and-Play Configuration Model

DHCP (RFC 2131) automatically assigns IP addresses, default gateways, subnet masks, and DNS server IPs to joining hosts.

The DHCP DORA Exchange (UDP Ports 67/68)
  • Discover: Client broadcasts DHCPDISCOVER to 255.255.255.255.
  • Offer: Server responds with DHCPOFFER proposing an IP lease.
  • Request: Client broadcasts DHCPREQUEST accepting the lease.
  • ACK: Server confirms with DHCPACK.

Network Address Translation (NAT) & Port Translation

4.1 Motivation & Private IP Protection

NAT (RFC 3022) allows an entire private local area network (e.g. 192.168.x.x) to share a single public IP address on the WAN, conserving IPv4 space.

4.2 NAPT Table Mechanics

The NAT router modifies outgoing IP packets by replacing private source IP/port with its public IP and a unique dynamic NAT port, storing the mapping in a translation table.

IPv6 Transition Strategies & Future Addressing

5.1 128-Bit IPv6 Address Architecture

IPv6 provides $2^{128} \approx 3.4 \times 10^{38}$ addresses, formatted as 8 groups of 4 hexadecimal digits (e.g., 2001:0db8:85a3::8a2e:0370:7334). Simplifies router processing by eliminating checksums and fragmentation fields from the fixed 40-byte base header.
