Mid-Semester Examination Blueprints

Section-wise question distributions, time allocations, tested coding problems, hardware schematics, and critical tips briefed directly by professors for the 12–22 October mid-sem exams.

Deep Learning

Exam Date: 15 Oct 2026 • Weightage: 20%
L01 – L11 (Current Week)
MCQs (70%) 30 Questions
Coding (30%) 3 Questions
Duration 2 Hours Strict

Exam Structure & Difficulty

  • Question Split: 30 MCQs (70% weightage) + 3 Coding questions (30% weightage).
  • Coding Tiers: 1 Easy, 1 Medium, and 1 Hard programming problem.
  • Difficulty Curve: 50–55% Medium, 10–15% Easy, and ~35% Hard difficulty.
  • Pacing Advisory: Paper is designed to be completed within 2 hours only if preparation is comprehensive.
Tested Topic Scope
Neuron foundations, activations (Sigmoid, Tanh, ReLU, Softmax), forward & backpropagation calculus, loss landscapes, optimizers (SGD, Momentum, NAG, AdaGrad, RMSProp, Adam), regularization (L1/L2, Dropout), and CNNs (LeNet, AlexNet, VGG, Inception, ResNet).

Computer Networks

Exam Date: 12 Oct 2026 • Weightage: 20%
L01 – L13
Objective MCQs 10 MCQs (20 Marks)
Comprehension 5 Case MCQs
Integer & Match 5 Int + 5 Match

Exam Structure & Question Formats

  • Standard MCQs: 10 questions (2 marks each = 20 marks total).
  • Comprehension MCQs: 5 questions formatted like contest re-tests.
  • Integer Type: 5 questions focused on subnet masks, IPv4 addressing, and usable hosts.
  • Match the Following: 5 protocol and layer mapping questions.
  • Subjective Paper: 5 questions total, including 2 physical diagram questions (5 marks diagram + 5 marks written theory).
  • Bonus & Exclusions: 1 Packet Tracer bonus question. Strictly NO coding and NO AWS questions.
Tested Topic Scope
Network core, packet switching, OSI & TCP/IP models, physical devices, application protocols (HTTP, DNS, SMTP, POP3, IMAP), HTTPS/TLS handshake, socket API, transport protocols (UDP, TCP flow & congestion control), IPv4 CIDR subnetting, and NAT.

Advanced Machine Learning

Exam Date: 22 Oct 2026 • Weightage: 25%
L01 – L12 (Till Logistic Lab)
MCQs & Numericals 60% (25–30 Ques)
Hands-on Coding 40% (4–5 Ques)
Lab Focus Logistic Regression

Exam Structure & Distribution

  • 60% Objective: 25–30 MCQs and integer numerical calculations.
  • 40% Coding: 4–5 Python implementation questions based on lab exercises.
  • Syllabus Horizon: Complete coverage from ML foundations up to the Logistic Regression lab session.
  • Mathematical Rigor: Expect closed-form OLS derivations, gradient update computations, and evaluation metrics calculations.
Tested Topic Scope
From code to learning foundations, ML lifecycle, simple & multiple linear regression via OLS, batch / stochastic / mini-batch GD, evaluation metrics (MSE, RMSE, R-squared, Confusion Matrix, F1), polynomial regression & assumptions, bias-variance tradeoff, feature selection, PCA, regularization (L1 Lasso & L2 Ridge), and logistic regression.

Modern Computer Architecture

Exam Date: 19 Oct 2026 • Weightage: 20%
L01 – L14 (Complete Scope)
Section A (Obj) 35 Marks (40 Min)
Section B (Coding) 65 Marks (4 Ques)
Sec C & D Subjective + Circuits

Four-Section Exam Architecture

  • Section A (35 Marks, 40 Min limit): 20 MCQs, 3 Integer type, 3 Match-the-Following (3 marks each).
  • Section B (65 Marks): 4 Coding questions (2 Verilog HDL + 2 MIPS Assembly programming).
  • Section C: 3 Subjective architectural analysis questions.
  • Section D (Written Paper): 2 Circuit drawings + Boolean equations (e.g. Half Adder), logic gates, and machine code instruction encoding/decoding (identifying R, I, J types).
  • Logistics & Bonus: Official reference sheet provided. Bonus question from upcoming logic gate circuit architecture & debugging (GATE questions link).

Must-Practice Assembly Programs & Logic Circuits

  • MIPS Programs: Even/Odd check, sum of N natural numbers, sum of odd/even within limits, sum of array elements, Factorial, and Fibonacci series.
  • Core Hardware Blocks: MUX, DEMUX, Half/Full Adder, Digital Counters, Registers, and 3-to-8 Decoder (8 outputs).
  • Lab Mastery: Review current and previous lab code thoroughly.
Tested Topic Scope
Boolean algebra, logic minimization, two's complement arithmetic, sequential feedback, latches, flip-flops, metastability, register files, FSMs, SRAM vs DRAM memory architecture, von Neumann bottleneck, RISC vs CISC principles, MIPS32 instruction formats (R, I, J), and stack calling conventions.
