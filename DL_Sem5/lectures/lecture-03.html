Vanishing Gradient: Sigmoid's Real Failure

1.1 Sigmoid at Saturation

From Lecture 02, the perceptron update rule is:

wnew = wold − α · (ŷ − y) · f′(z) · x    where z = wx + b

Last lecture tested sigmoid at its best point (z = 0, σ′ = 0.25). Now consider a perceptron that is almost as wrong as possible — with a large weight w = 6:

  • z = 6 → ŷ = σ(6) = 0.99752738 — error is 99.75% of maximum
  • σ′(6) = σ(6)·(1−σ(6)) = 0.00246651 — derivative is nearly zero
  • ∂L/∂w = 0.00246041 → step = 0.0025 (despite a massive error!)
  • wnew = 5.99753959 — barely moved

⚠️ The Contradiction: Error was 99.75% of maximum, yet the step was only 0.0025. The culprit:

Vanishing Gradient: When |z| is large, sigmoid is flat → σ′(z) ≈ 0 → gradient ≈ 0 → no learning

1.2 Tanh Doesn't Fix It

Tanh has a taller peak (max f′ = 1.0 vs 0.25) — looks like the cure. But:

  • Near z = 0: tanh′ is steeper than σ′ ✓
  • The two derivative curves cross at z = 1.663
  • Beyond the crossing, tanh′ falls below σ′ and drops faster
  • At z = 6: both derivatives ≈ 0

Tanh wins near the origin and loses badly once |z| grows. Both are S-shaped, both saturate, both vanish. The S-shape itself is the problem — no rescaling of an S-curve fixes this.

ReLU — Rectified Linear Unit

2.1 Definition & Positive Side

Instead of bending an S, use a function that never flattens on the positive side:

f(z) = max(0, z) = z if z > 0, else 0
f′(z) = 1 if z > 0, else 0    (f′(0) undefined; libraries use 0)

Critical property: f′(z) = 1 for all z > 0. There is no z in it, so the derivative cannot shrink — f′(6) = 1, f′(600) = 1.

Worked example (same setup as Part 2): x=1, w=6, b=0, y=0, α=1

  • z = 6 → ŷ = max(0, 6) = 6
  • ŷ − y = 6  |  f′(6) = 1  |  ∂L/∂w = 6
  • wnew = 6 − 1·6·1·1 = 0 → verify: z=0, ŷ=0, error=0 ✓

Solved in one step — on the same problem where sigmoid moved by only 0.0025.

Activation f′(6) Step taken
Sigmoid 0.00246651 0.00246041
ReLU 1 6  (≈ 2439× bigger)

2.2 Where ReLU Lives in a Network

ReLU's output is unbounded (ReLU(6) = 6 — not a probability). So it cannot be the final-layer activation:

  • Hidden layers: ReLU is the standard default — cheap and no vanishing gradient for z > 0
  • Output layer (binary): Sigmoid squashes output to [0, 1]
  • Output layer (multi-class): Softmax (introduced in Topic 7)

Dead Neuron: ReLU's Negative Side

3.1 Dead Neuron Numerically

Test ReLU when z < 0: x=1, w=−3, b=0, y=1, α=1

  • z = −3 → ŷ = max(0, −3) = 0
  • ŷ − y = −1  |  f′(−3) = 0 (z is negative → derivative is exactly 0)
  • ∂L/∂w = (−1)·0·1 = 0 → wnew = −3 (no change)
Dead Neuron: When z < 0, f′(z) = 0 → gradient = 0 → permanently stuck (α = 1,000,000 still gives zero step)

Unlike sigmoid's vanishing gradient (gradient is merely small), ReLU's dead neuron problem is absolute — the gradient is exactly zero. No learning rate can rescue a product containing zero.

3.2 Why Identity Function Fails

Tempting fix: "Use f(z) = z everywhere — slope 1, derivative never zero."

But substituting f(z) = z: ŷ = f(wx + b) = wx + b. The activation function does nothing. A straight line fed into a straight line is still a straight line. However many layers are stacked, the whole network is still one linear function and can never learn a non-linear decision boundary.

What we need: a non-zero derivative on the negative side and a shape that is not one straight line (so the network can still bend).

4

Leaky ReLU

4.1 Definition & The Fix

Keep the negative side as a straight line, but give it a different slope (0.01) from the positive side (1). That single difference creates a bend at z = 0 — it is no longer one straight line:

f(z) = z if z > 0, else 0.01·z
f′(z) = 1 if z > 0, else 0.01

Worked example (same negative problem): x=1, w=−3, b=0, y=1, α=1

  • z = −3 → ŷ = 0.01·(−3) = −0.03
  • f′(−3) = 0.01  |  ∂L/∂w = (−1.03)·(0.01)·1 = −0.0103
  • wnew = −3 − (−0.0103) = −2.9897 ✅ Alive!

4.2 Weaknesses of Leaky ReLU

  • Tiny negative output: ŷ = −0.03 (barely different from zero — crawling, not running)
  • Derivative discontinuity at z = 0: f′ jumps from 0.01 to 1 — not a smooth derivative
  • Arbitrary hand-chosen constant: Why 0.01? Not 0.001 or 0.1? This is a hyperparameter requiring tuning
5

ELU — Exponential Linear Unit

5.1 Definition & Smooth Derivative

Keep f(z) = z for z > 0 (same as ReLU). Replace the flat/straight negative part with a smooth exponential curve that floors at −1:

f(z) = z if z > 0, else eᶻ − 1
f′(z) = 1 if z > 0, else eᶻ

Two key checks:

  • As z → −∞: eᶻ → 0, so f(z) → −1. The negative side is bounded — not a straight line running to −∞
  • At z = 0: f′(0⁺) = 1, f′(0⁻) = e⁰ = 1. They agree → no jump → continuous derivative (unlike Leaky ReLU)

Worked example (same problem, e⁻³ = 0.049787): x=1, w=−3, b=0, y=1, α=1

  • z = −3 → ŷ = e⁻³ − 1 = −0.950213
  • f′(−3) = e⁻³ = 0.049787  |  ∂L/∂w = −1.950213 × 0.049787 = −0.097095
  • wnew = −3 + 0.097095 = −2.902905

5.2 ELU vs Leaky ReLU Comparison

Activation ŷ at z=−3 f′(−3) ∂L/∂w w: −3 → Verdict
ReLU 0 0 0 −3 💀 Dead
Identity −3 1 −4 1 ⚠️ Network = 1 straight line
Leaky ReLU −0.03 0.01 −0.0103 −2.9897 🐢 Alive, crawling
ELU −0.9502 0.0498 −0.0971 −2.9029 ✅ Alive, properly moving (~9.4× faster)

Full Activation Function Comparison

6.1 Mathematical Summary

Function f(z) f′(z) Range Max f′
Threshold 1 if z≥0, else 0 0 {0,1} 0
Sigmoid 1/(1+e⁻ᶻ) σ(1−σ) (0,1) 0.25
Tanh (eᶻ−e⁻ᶻ)/(eᶻ+e⁻ᶻ) 1−tanh²z (−1,1) 1
ReLU max(0,z) 1 or 0 [0,∞) 1
Leaky ReLU z or 0.01z 1 or 0.01 (−∞,∞) 1
ELU z or eᶻ−1 1 or eᶻ (−1,∞) 1
Softmax eᶻⁱ/Σeᶻʲ (cross-layer) (0,1), sums to 1 —

6.2 Practical Use Cases

Function Advantage Disadvantage Typical Use
Sigmoid Output = probability Vanishing gradient; max f′=0.25 Final layer (binary), LSTM gates
Tanh Zero-centred, steeper near origin Saturates faster than sigmoid RNN/LSTM hidden states
ReLU No vanishing gradient (z>0); cheap Dead neuron (z<0); unbounded output Default hidden layers (CNNs)
Leaky ReLU Never dies; cheap as ReLU Tiny negative output; jump at z=0; hand-picked slope GANs (dead units destabilise)
ELU Never dies; smooth at z=0; bounded below Exponential is slower than ReLU When too many ReLU units are dying
Softmax Probabilities that sum to 1 Meaningful only across entire layer Final layer (multi-class)

Softmax — Multi-class Classification

7.1 Definition & Worked Numerical

Sigmoid outputs one probability between 0 and 1 — it answers yes/no. For three classes (cat, dog, bird), three separate sigmoids don't work: they answer independently and don't sum to 1. Softmax takes all n raw scores together:

softmax(zᵢ) = eᶻⁱ / Σⱼ eᶻʲ

The exponential makes every value positive. Dividing by the total forces them to sum to 1.

Worked numerical: z₁ = 2.0 (cat), z₂ = 1.0 (dog), z₃ = 0.1 (bird)

  1. Exponentiate: e²·⁰ = 7.389056, e¹·⁰ = 2.718282, e⁰·¹ = 1.105171
  2. Sum: Σeᶻ = 11.212509
  3. Divide: p₁ = 0.659, p₂ = 0.242, p₃ = 0.099
  4. Check: 0.659 + 0.242 + 0.099 = 1.000 ✓
  5. Decision: cat at 65.9% confidence

✨ Order preserved: The largest raw score still gives the largest probability. Softmax doesn't change which class wins — only converts scores to interpretable probabilities.

7.2 Softmax as Generalized Sigmoid

Sigmoid is softmax for two classes. With n=2, scores z and 0:

softmax(z) = eᶻ / (eᶻ + e⁰) = eᶻ / (eᶻ + 1) = 1 / (1 + e⁻ᶻ) = σ(z)

Binary classification is a special case of multi-class, not a separate idea.

Quick reference:

Task Final-layer Activation Output Units
Binary classification Sigmoid 1
Multi-class classification Softmax One per class
Hidden layers ReLU (Leaky ReLU / ELU if dying) Any
