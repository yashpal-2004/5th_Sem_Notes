Executive Summary & Formula Sheet

Lecture 04 Quick Ref

Core Concept: A single perceptron cannot solve non-linearly separable functions like XOR. Adding a hidden layer transforms space into a new feature representation where points become linearly separable. Backpropagation uses the chain rule to recursively compute loss gradients with respect to every weight across layers.

  • Forward Pass: \(\mathbf{z}^{[l]} = \mathbf{W}^{[l]} \mathbf{a}^{[l-1]} + \mathbf{b}^{[l]}\), \(\mathbf{a}^{[l]} = g(\mathbf{z}^{[l]})\)
  • Parameter Count: For layer with \(N_{\text{in}}\) inputs and \(N_{\text{out}}\) neurons: \(\text{Params} = (N_{\text{in}} \times N_{\text{out}}) + N_{\text{out}}\)
  • Output Error Signal: \(\delta^{[L]} = (\hat{y} - y) \odot g'(\mathbf{z}^{[L]})\)
  • Hidden Error Signal: \(\delta^{[l]} = (\mathbf{W}^{[l+1]T} \delta^{[l+1]}) \odot g'(\mathbf{z}^{[l]})\)
  • Weight Update Gradient: \(\frac{\partial \mathcal{L}}{\partial \mathbf{W}^{[l]}} = \delta^{[l]} (\mathbf{a}^{[l-1]})^T\)
Topic 01

1. Resolving XOR with Hidden Layers

1.1 Why Single Linear Boundary Fails

XOR truth table outputs 1 for (0,1) and (1,0), and outputs 0 for (0,0) and (1,1). No single straight line \(w_1 x_1 + w_2 x_2 + b = 0\) can separate (0,1) and (1,0) from (0,0) and (1,1) simultaneously because the convex hulls of the two sets intersect.

1.2 Combining OR and NAND Gates

XOR can be expressed logically as \(x_1 \oplus x_2 = (x_1 \lor x_2) \land \neg(x_1 \land x_2)\). In a network, one hidden neuron computes OR (\(h_1\)), another computes NAND (\(h_2\)), and the output neuron computes AND(\(h_1, h_2\)). The hidden layer re-maps 2D input space into a 2D hidden space where (0,0) becomes (0,1), (1,1) becomes (1,0), and (0,1)/(1,0) both map to (1,1)—making them linearly separable!

Topic 02

2. Multilayer Perceptron (MLP) Architecture

2.1 Input, Hidden, and Output Layers

An MLP consists of an input layer (pass-through nodes), one or more hidden layers (dense linear combinations followed by non-linear activations), and an output layer producing predictions \(\hat{y}\).

2.2 Weight Matrix & Bias Vector Notation

\(W_{ij}^{[l]}\) represents the weight connecting neuron \(j\) in layer \(l-1\) to neuron \(i\) in layer \(l\). Bias vector \(b_i^{[l]}\) shifts the linear sum for neuron \(i\) in layer \(l\).

Topic 03

3. Parameter Counting Rules

3.1 Formula for Layer Parameters

For a fully connected layer with \(N_{\text{in}}\) input nodes and \(N_{\text{out}}\) output nodes: number of weights = \(N_{\text{in}} \times N_{\text{out}}\), number of biases = \(N_{\text{out}}\). Total parameters = \(N_{\text{out}} \times (N_{\text{in}} + 1)\).

3.2 Worked Example: 3-3-1 Network

A 3-3-1 MLP has 3 inputs, 3 hidden neurons, and 1 output neuron:

  • Hidden Layer Parameters: \((3 \times 3) \text{ weights} + 3 \text{ biases} = 12\)
  • Output Layer Parameters: \((3 \times 1) \text{ weights} + 1 \text{ bias} = 4\)
  • Total Network Parameters = \(12 + 4 = 16\)
Topic 04

4. Forward Propagation Equations

4.1 Layer-wise Computation Flow

Starting from inputs \(\mathbf{a}^{[0]} = \mathbf{x}\), each layer computes linear pre-activation \(\mathbf{z}^{[l]} = \mathbf{W}^{[l]}\mathbf{a}^{[l-1]} + \mathbf{b}^{[l]}\) and applies activation \(\mathbf{a}^{[l]} = g(\mathbf{z}^{[l]})\) sequentially until reaching \(\mathbf{a}^{[L]} = \hat{y}\).

4.2 Matrix-Vector Multiplication Form

Vectorizing computations allows modern hardware (GPUs) to compute activations for thousands of samples simultaneously using matrix multiplication \(\mathbf{Z}^{[l]} = \mathbf{W}^{[l]}\mathbf{A}^{[l-1]} + \mathbf{b}^{[l]}\).

Topic 05

5. Backpropagation Error Derivatives

5.1 Output Layer Gradient Derivation

For loss \(\mathcal{L} = \frac{1}{2}(\hat{y} - y)^2\) and output activation \(\hat{y} = g(z^{[L]})\):

\(\delta^{[L]} = \frac{\partial \mathcal{L}}{\partial z^{[L]}} = \frac{\partial \mathcal{L}}{\partial \hat{y}} \frac{\partial \hat{y}}{\partial z^{[L]}} = (\hat{y} - y) g'(z^{[L]})\)

5.2 Hidden Layer Error Signal Backpropagation

By applying the chain rule backward, the error signal \(\delta^{[l]}\) at hidden layer \(l\) is computed by taking the weighted sum of future error signals \(\mathbf{W}^{[l+1]T}\delta^{[l+1]}\) and multiplying elementwise by local activation derivative \(g'(\mathbf{z}^{[l]})\).

Topic 06

6. Numerical Backpropagation Step-by-Step

6.1 Squared Error Loss Setup

Given network input \(x=1\), target \(y=1\), learning rate \(\alpha=0.5\), weights \(w^{[1]}=0.5, b^{[1]}=0, w^{[2]}=0.8, b^{[2]}=0\), and Sigmoid activations.

6.2 End-to-End Weight Update Walkthrough

  • \(z^{[1]} = 0.5 \times 1 = 0.5 \implies a^{[1]} = \sigma(0.5) = 0.6225\)
  • \(z^{[2]} = 0.8 \times 0.6225 = 0.498 \implies \hat{y} = \sigma(0.498) = 0.6220\)
  • \(\text{Loss } \mathcal{L} = \frac{1}{2}(0.6220 - 1)^2 = 0.0714\)
  • \(\delta^{[2]} = (0.6220 - 1) \cdot \sigma'(0.498) = -0.3780 \cdot (0.6220 \times 0.3780) = -0.0889\)
  • \(\frac{\partial \mathcal{L}}{\partial w^{[2]}} = \delta^{[2]} a^{[1]} = -0.0889 \times 0.6225 = -0.0553 \implies w^{[2]}_{\text{new}} = 0.8 - 0.5(-0.0553) = 0.8277\)
  • \(\delta^{[1]} = (\delta^{[2]} w^{[2]}) \cdot \sigma'(0.5) = (-0.0889 \times 0.8) \cdot 0.2350 = -0.0167\)
  • \(\frac{\partial \mathcal{L}}{\partial w^{[1]}} = \delta^{[1]} x = -0.0167 \times 1 = -0.0167 \implies w^{[1]}_{\text{new}} = 0.5 - 0.5(-0.0167) = 0.5084\)
