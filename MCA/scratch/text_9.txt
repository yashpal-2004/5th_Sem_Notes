Two Flavours: Moore vs Mealy
The difference is simply WHERE the output comes from.
MOORE MACHINE MEALY MACHINE
Output depends on the STATE only Output depends on STATE + INPUT
The output is written inside each state circle The output is written on each transition arrow
It changes only when the state changes It can react to an input within the same cycle
Simpler to reason about, and glitch-free Often needs fewer states
May need more states to do the same job Output can glitch when the input glitches
Output appears one cycle after the input Output appears in the same cycle as the input
Rule of thumb: Moore = 'output in the circle', Mealy = 'output on the arrow'. Both compute the same things.

The read address is the select code — it

flows to that port.

Reads Are Instant, Writes Wait for the Clock
This asymmetry is the single most important fact about a register file.
READ = COMBINATIONAL WRITE = SYNCHRONOUS
No clock needed Happens on the clock edge
Put an address on a read port… Address + data + WE are set up early…
…the data appears after just gate delay. …the register updates only at the edge.
Both read ports work this way, at once. This prevents races and half-written values.
So the ALU gets its operands immediately. The new value is readable next cycle.
Why it works: read the old values combinationally at the start of a cycle, compute, then write the result at the edge —
read-before-write, safely, in one cycle.

L07 · MODERN COMPUTER ARCHITECTURE 32 / 34
Key Takeaways
Five sentences — the CPU's storage and its controller.
01 A register file packs many registers (RISC: 32 × 32-bit) into one block with 2 read ports and 1 write port.
02 The write port uses a decoder + write-enable to update exactly one register on the clock edge (synchronous).
03 The read ports are MUX-based and combinational — two operands appear instantly, no clock needed.
04 An FSM = states + inputs + transitions + outputs, built as next-state logic → state register → output logic.
05 Moore output = f(state) (in the circle); Mealy output = f(state, input) (on the arrow) — Mealy often uses fewer states.
