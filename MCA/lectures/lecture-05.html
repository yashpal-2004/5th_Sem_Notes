Quick summary and key formulas for Lecture 05:

Key Equations & State Rules
  • Combinational Logic: \(\text{Output} = f(\text{Inputs NOW})\) (Stateless, zero memory).
  • Sequential Logic: \(\text{Output} = f(\text{Inputs NOW}, \text{Past State})\) (Stateful memory created via feedback).
  • NOR SR Latch States: \(S=0, R=0 \implies \text{Hold }(Q)\); \(S=1, R=0 \implies \text{Set }(Q=1)\); \(S=0, R=1 \implies \text{Reset }(Q=0)\); \(S=1, R=1 \implies \text{FORBIDDEN!}\)
  • D Latch Equation: \(Q_{\text{next}} = D\) (when Enable \(EN = 1\)), holds \(Q\) (when \(EN = 0\)). Elimination of forbidden state!
1

Combinational vs. Sequential Logic

1.1 Statutory Differences & Memory Concept

All digital circuits studied in Lectures 1–4 (adders, MUXes, decoders) were strictly combinational: their output vector is determined purely by the current input vector. The moment inputs change or disconnect, the past computation vanishes instantly.

A CPU cannot operate without storing information (registers, program counters, memory caches). This requires sequential logic, where circuits store internal state.

Architectural Comparison
  • Combinational Logic: Output depends solely on current inputs. Stateless, reactive, no memory, no feedback loops (e.g., MUX, Full Adder).
  • Sequential Logic: Output depends on current inputs AND internal stored history. Stateful, memory-capable, contains feedback loops (e.g., Registers, Counters).

1.2 State Representation & History Dependence

In sequential logic, identical input values can produce different output values depending on the system's prior history. A clock signal coordinates when state updates are permitted to occur.

2

The Origin of Memory: Feedback Loops

2.1 Self-Sustaining Feedback Paths

How does a circuit built from static logic gates gain memory? The fundamental breakthrough is feedback—routing a gate's output line back into its own input path.

In a simple open line, signals travel left-to-right and disappear. When closed into a feedback loop, the output signal continuously reinforces itself, enabling the circuit to "hold itself up" even after external inputs drop.

2.2 Bistable Element (Cross-Coupled Inverters)

The simplest 1-bit memory cell consists of two inverters connected in a closed ring (cross-coupled inverters).

Bistable Operation

This ring has exactly two stable equilibrium states:

  • State 1: Node \(A = 0 \implies \text{Inverter 1 outputs } B = 1 \implies \text{Inverter 2 reinforces } A = 0\).
  • State 2: Node \(A = 1 \implies \text{Inverter 1 outputs } B = 0 \implies \text{Inverter 2 reinforces } A = 1\).

The Limitation: While this element holds 1 bit indefinitely, it is completely sealed—there are no control terminals to change the stored bit! Adding control inputs creates a Latch.

3

The SR Latch (NOR & NAND Versions)

3.1 NOR-Based SR Latch Truth Table

By replacing the inverters in the bistable loop with cross-coupled NOR gates, we introduce two control terminals: Set (\(S\)) and Reset (\(R\)).

NOR SR Latch State Matrix
  • \(S=0, R=0 \implies \mathbf{\text{HOLD}}\): Output \(Q\) remains unchanged (remembers stored bit).
  • \(S=1, R=0 \implies \mathbf{\text{SET}}\): Forces output \(Q = 1\) (and \(\bar{Q} = 0\)).
  • \(S=0, R=1 \implies \mathbf{\text{RESET}}\): Forces output \(Q = 0\) (and \(\bar{Q} = 1\)).
  • \(S=1, R=1 \implies \mathbf{\text{FORBIDDEN!}}\): Invalid state. Forces both \(Q=0\) and \(\bar{Q}=0\), breaking the complement invariant (\(Q \neq \bar{Q}\)).

3.2 Active-Low NAND-Based SR Latch

An SR latch built from cross-coupled NAND gates operates on active-LOW inputs (\(\bar{S}, \bar{R}\)). Asserting a 0 triggers Set or Reset, and \(\bar{S}=\bar{R}=0\) represents the forbidden state.

3.3 The Forbidden State (\(S=R=1\)) & Race Hazard

Why \(S=R=1\) is Dangerous

If \(S\) and \(R\) are both driven high simultaneously and then transition back to 0 at the same instant, the latch enters a Race Condition. Due to tiny nanosecond differences in gate propagation delays, the final stored state becomes completely unpredictable.

4

The D Latch & Gated Enable

4.1 Engineering Away the Forbidden State

To prevent the forbidden state (\(S=R=1\)), digital designers created the D Latch (Data Latch). It uses a single Data input (\(D\)) and passes \(D\) directly to \(S\) while passing \(\bar{D}\) (via an inverter) to \(R\). Because \(S\) and \(R\) are guaranteed to be opposite, \(S=R=1\) is physically impossible.

4.2 Gated Clock Enable & Level Transparency

Adding an Enable (\(EN\)) control line creates a Gated D Latch:

\(Q_{\text{next}} = D \text{ (when } EN=1 \text{)}, \quad Q_{\text{next}} = Q \text{ (when } EN=0 \text{)}\)
Level Transparency Property

While \(EN = 1\), the D Latch is transparent: any changes on input line \(D\) continuously flow straight through to output \(Q\). When \(EN\) drops to 0, the latch opaque-locks the last valid bit present on \(D\).

5

Practical Limits of Latches

5.1 Level Transparency Risks & Data Slippage

While D Latches store bits cleanly, their level transparency creates severe hazards in pipelined CPU architectures. Because the latch remains open during the entire high duration of the clock pulse, data can "race through" multiple cascaded latches in a single clock cycle, corrupting internal CPU registers.

5.2 Transitioning to Clock-Edge Triggering

To build reliable CPU registers and pipelines, hardware engineers require storage elements that sample data at one precise instant in time (a clock edge) rather than an entire high window. This leads to the Flip-Flop (covered in Lecture 06 & 07).
