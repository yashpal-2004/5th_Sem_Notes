Short Notes & Visual Summary

Quick summary and key formulas for Lecture 06:

Key Definitions & Rules
  • Latch (Level-Triggered): Transparent during clock level (HIGH or LOW). Data races can occur.
  • Flip-Flop (Edge-Triggered): Samples input at one precise clock INSTANT (\(0 \to 1\) rising edge). Locks output for rest of cycle.
  • Setup Time (\(t_{\text{setup}}\)): Minimum time data \(D\) must be stable BEFORE the clock edge.
  • Hold Time (\(t_{\text{hold}}\)): Minimum time data \(D\) must remain stable AFTER the clock edge.
  • Maximum Clock Frequency Constraint: \(T_c \ge t_{\text{pcq}} + t_{\text{pd, combinational}} + t_{\text{setup}}\)
1

Level vs. Edge Triggering

1.1 Level-Sensitive Window vs. Edge Moment

The transition from latches to flip-flops centers on how data sampling is gated by a clock signal:

Triggering Mechanisms
  • Level-Triggered (Latch): Active during an entire clock LEVEL (e.g., while \(\text{CLK}=1\)). The output continuously tracks changes on input line \(D\) throughout the high window (transparent).
  • Edge-Triggered (Flip-Flop): Active ONLY during the instantaneous transition of the clock (e.g., \(0 \to 1\) rising edge). It captures a single snapshot of \(D\) at that exact nanosecond moment and freezes the output for the remainder of the clock period.

1.2 Why Registers Require Edge Triggering

An edge is an instantaneous moment in time (\(0 \to 1\)), not a duration. By capturing data strictly on clock edges, pipelined CPU registers guarantee that data cannot race through multiple sequential stages within a single clock cycle.

2

Master-Slave D Flip-Flop

2.1 Two-Stage Airlock Architecture

An edge-triggered Master-Slave D Flip-Flop is constructed by connecting two D latches in series driven by inverted clock signals.

Master-Slave Airlock Model

Stage 1 (Master Latch): Gated by \(\text{CLK}\).
Stage 2 (Slave Latch): Gated by \(\overline{\text{CLK}}\).

Because the Master and Slave latches are driven by complementary clock signals, they are never open at the same time. This acts as a two-stage airlock that prevents data from racing straight through.

2.2 Step-by-Step Clock Phase Hand-off

  1. When \(\text{CLK} = 1\): Master latch is open/transparent and tracks input \(D\). Slave latch is opaque and holds the previous output \(Q\).
  2. On the Falling Edge (\(1 \to 0\)): Master latch closes and freezes the captured bit \(Q_{\text{master}}\). Simultaneously, Slave latch opens and passes \(Q_{\text{master}}\) to output \(Q\).
3

Latch vs. Flip-Flop Comparison

3.1 Comprehensive Architectural Matrix

Understanding when to use latches versus flip-flops is a core requirement in hardware design:

Feature Latch Flip-Flop
Triggering Clock LEVEL (High/Low) Clock EDGE (Rising/Falling)
Transparency Yes (while clock is high) No (samples at edge instant)
Gate Count Fewer (~1x size) More (~2x size of latch)
Data Race Risk High (requires careful timing) Blocked (safe for pipelines)
Primary Use Case Asynchronous buffering, SRAM CPU Registers, PC, Pipelines

3.2 Schematic Symbol Recognition

In digital schematics, a Flip-Flop is identified by a small triangle symbol (\(>\)) on the clock input pin, indicating edge-sensitivity. A latch has a plain clock pin without the triangle.

4

Timing Parameters: Setup & Hold

4.1 Setup Time (\(t_{\text{setup}}\)) Definition

Flip-flops cannot capture signals that change simultaneously with the clock edge. Setup Time (\(t_{\text{setup}}\)) is the minimum duration data input \(D\) must remain completely stable BEFORE the active clock edge arrives.

4.2 Hold Time (\(t_{\text{hold}}\)) & Aperture Window

Hold Time (\(t_{\text{hold}}\)) is the minimum duration data input \(D\) must remain stable AFTER the active clock edge has passed.

The Camera Shutter Analogy

Sampling data with a flip-flop is like taking a photo of a moving athlete. The athlete must stand completely still for a brief instant before AND after the shutter clicks (\(t_{\text{setup}} + t_{\text{hold}}\)); otherwise, the resulting image is blurred (corrupted bit).

5

Timing Violations & Propagation Delays

5.1 Setup/Hold Violations

If data changes inside the setup or hold aperture window, a Timing Violation occurs. The flip-flop may capture an incorrect value or enter a dangerous state known as Metastability (detailed in Lecture 07).

5.2 Propagation Delay (\(t_{\text{pcq}}\) & \(t_{\text{ccq}}\))

Flip-flop output \(Q\) does not update instantly on the clock edge; it incurs physical gate delays:

  • \(t_{\text{pcq}}\) (Propagation Delay Clock-to-Q): Maximum time after clock edge until output \(Q\) achieves a stable valid logic level.
  • \(t_{\text{ccq}}\) (Contamination Delay Clock-to-Q): Minimum time after clock edge before output \(Q\) begins changing.
\(\text{Max Clock Speed } f_{\max} = \frac{1}{t_{\text{pcq}} + t_{\text{combinational, max}} + t_{\text{setup}}}\)
